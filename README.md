# Bookstore Sales Analysis

This project uses SQL to explore bookstore sales data, book ratings, and publisher performance.

## What I analysed

- Top-selling books
- Books with sales above the average
- Average ratings by genre
- Publisher revenue rankings
- Author performance and ratings
- Sales by publishing year
- Revenue and profitability comparisons

## SQL concepts used

- Joins
- Aggregate functions and GROUP BY
- Subqueries
- Common Table Expressions (CTEs)
- Window functions and RANK()
- Filtering and sorting

## Tools

- SQL
- MySQL

## File

`Bookstore Sales Analysis.sql` contains the SQL queries used for the analysis.
